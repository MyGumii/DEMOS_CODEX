확산 모델부터 천천히

Stable Diffusion은 픽셀보다 작은 잠재 공간에서 “노이즈를 조금씩 제거”합니다. 텍스트는 cross-attention을 통해 어느 시각 특징을 강조할지 알려줍니다.

01

프롬프트

“고흐 스타일의 교회”처럼 원하는 내용을 씁니다.

02

텍스트 임베딩

문장을 숫자 벡터 c로 바꿉니다.

03

Cross-attention

단어와 이미지 위치·특징을 연결합니다.

04

U-Net denoising

각 시점 t에서 섞인 노이즈를 예측합니다.

05

Decoder

깨끗해진 잠재 표현을 최종 이미지로 복원합니다.

확산 모델 = 안개 낀 그림을 복원하는 화가

화가는 매 단계 “어느 방향으로 붓질하면 노이즈가 줄까?”를 예측합니다.

Cross-attention = 통역사 겸 스포트라이트

“교회”라는 단어가 이미지의 어느 영역과 특징에 연결되는지 알려줍니다.

기본 학습 수식

Ldiff = E[ ‖ ε − εθ(xt, t, c) ‖² ]

정답 노이즈 ε와 모델이 예측한 노이즈 εθ의 차이를 줄입니다. 차이가 작을수록 안개를 더 정확히 걷어냅니다.

θ: 모델 가중치xt: t시점의 noisy latentc: 텍스트 조건

Concept erasure의 공통 목표

목표 E는 생성 ↓   |   나머지 P = C \ E는 유지 ↑

문제는 개념이 서랍처럼 분리되어 있지 않다는 점입니다. “nudity”를 누르면 “person”, “skin”, “body”의 표현도 함께 흔들릴 수 있습니다.

수식 실험실: ESD의 ‘반대 방향 교사’

일반 CFG는 조건 방향을 더합니다. ESD는 그 방향을 빼서, 편집 모델이 목표 개념에서 멀어지도록 학습합니다. 아래 값은 벡터를 숫자 하나로 줄인 직관용 장난감 예시입니다.

ICCV 2023 · Gandikota et al.

Erasing Concepts from Diffusion Models

추가 이미지 데이터 없이, 원래 모델의 conditional / unconditional 예측만으로 모델 가중치에서 특정 개념을 억제하는 ESD를 제안합니다.

이 논문의 질문

“안전 필터가 아니라 모델 자체가 그 개념을 덜 알게 만들 수 있을까?”

방법 flow

  1. 삭제할 짧은 텍스트 c만 준다.
  2. 동결된 원본 모델에서 무조건 예측 u와 조건 예측 c를 얻는다.
  3. 조건이 만든 차이 (c−u)를 반대로 민 target을 만든다.
  4. 편집 모델이 그 target을 예측하도록 U-Net 일부를 fine-tune한다.

핵심 수식

ε̄ = εθ*(xt,t) − η[εθ*(xt,c,t) − εθ*(xt,t)]
LESD = E ‖εθ′(xt,c,t) − ε̄‖²

번역: “c가 만든 붓질”을 더하는 대신 같은 만큼 반대로 가도록 새 모델을 훈련합니다.

숫자 예: u=2, c=5, η=1이면 ε̄=−1. 편집 모델은 c를 봐도 5가 아니라 −1 쪽을 모방합니다.

Contribution

  • 이미지 데이터 없이 모델 자체의 지식을 교사로 사용.
  • ESD-x: cross-attention만 바꿔 prompt-specific 삭제.
  • ESD-u: cross-attention 이외를 바꿔 prompt 표현과 무관한 더 넓은 삭제.
  • style, object, nudity에 가중치 기반 삭제를 실증.

Limit

  • ESD-x는 명시적 token에 좁게 반응해 동의어·우회 prompt에 취약할 수 있음.
  • ESD-u는 넓게 작동하지만 주변 시각 능력의 간섭 위험이 큼.
  • 초기 평가는 주로 직접 prompt와 단일 target 중심; 후속 연구가 공격·조합·계층 우회를 보임.
  • 행동 억제이지, 학습 데이터 삭제의 엄밀한 증명은 아님.
마지막 두 항목은 후속 연구를 반영한 해석
ECCV 2024 · Huang et al.

Receler: Reliable Concept Erasing via Lightweight Erasers

원본 U-Net은 동결하고 cross-attention 뒤에 작은 Eraser를 붙여, locality와 robustness를 동시에 노립니다.

이 논문의 질문

“모델 전체를 망가뜨리지 않고, 말 바꾸기 공격에도 버티는 작은 지우개를 붙일 수 있을까?”

방법 flow

  1. 각 cross-attention 뒤에 bottleneck Eraser를 삽입.
  2. ESD식 negative target으로 목표 개념을 억제.
  3. attention map으로 목표 위치 mask M을 만들고, mask 밖 Eraser 출력을 벌점.
  4. 목표를 복구하려는 soft adversarial prompt를 번갈아 학습하고 다시 삭제.

핵심 수식 두 개

LReg = (1/L) Σl ‖ ol ⊙ (1−M̃) ‖²

목표 영역 밖에서 Eraser가 손대면 벌점입니다. “사진 전체를 지우지 말고 대상이 있던 자리만 고쳐라”에 가깝습니다.

LAdv = E ‖ εθ′(xt, [ec;eadv],t) − εθ(xt,ec,t) ‖²

eadv는 지운 개념을 되살리는 공격 prompt를 배우고, Eraser는 그것을 다시 지웁니다.

Contribution

  • Eraser가 U-Net 파라미터의 0.37%만 차지.
  • mask 기반 concept-localized regularization으로 locality 강화.
  • paraphrase·learned prompt를 흉내 내는 adversarial learning.
  • 실험에서 ESD 대비 object robustness와 fidelity를 함께 개선.

Limit

  • 논문 명시: 공격자가 원본 weight에 접근하면 Eraser를 제거해 원 모델을 복구할 수 있음.
  • 개념마다 별도 Eraser를 약 1시간(V100) 학습; 다중 삭제는 개별 출력을 평균.
  • 삭제 세기를 높이면 locality가 나빠지는 trade-off가 보충자료에 확인됨.
  • SD v1.4와 제한된 object/unsafe concept 실험 중심.
ECCV 2024 Oral · Kim, Min & Yang

R.A.C.E.: Robust Adversarial Concept Erasure

삭제된 개념을 되살리는 adversarial text embedding을 한 timestep에서 빠르게 찾고, 그 주변까지 함께 지우도록 adversarial training합니다.

이 논문의 질문

“직접 prompt는 막았지만 embedding을 살짝 비틀면 다시 나타나는 문제를 어떻게 막을까?”

방법 flow

  1. 기존 ESD 모델에서 target image latent를 준비.
  2. t*=500 같은 단일 시점에서 PGD로 작은 δ를 찾음.
  3. c+δ가 삭제 개념을 다시 복원하게 만드는지 확인.
  4. 이 가장 나쁜 이웃 embedding도 ESD의 neutral target으로 보내도록 반복 학습.

안쪽 공격 + 바깥 방어

δ* = arg min‖δ‖∞≤ε ‖ n − Φθ(z̃t,t,c+δ) ‖²

먼저 “이 금지 이미지를 가장 잘 설명하는 작은 prompt 변형”을 찾습니다.

LRACE = ‖ Φθ(zt,t,c+δ*) − ε̄ESD ‖²

다음에는 그 변형까지 반대 방향 target에 맞춥니다. 중심 한 점이 아니라 반경 ε의 이웃을 함께 눌러주는 셈입니다.

Contribution

  • 모든 timestep 대신 단일 timestep 공격으로 adversarial training 비용 절감.
  • 추가 모듈이나 외부 prompt/image 없이 ESD에 결합 가능.
  • white-box와 black-box red-team 평가.
  • nudity에서 강한 white-box 공격 대비 ASR을 약 30–33%p 낮춤.

Limit

  • 논문 명시: robustness가 강해질수록 FID/품질과 non-target 정확도가 나빠지는 경향.
  • ε-neighborhood와 선택한 t*가 방어 범위를 정의하므로 모든 언어적 우회를 포괄한다고 보장하지 않음.
  • L1 weight regularization과 유사 keyword 확대가 완화책이지만, 다시 품질 trade-off를 만듦.
  • 주 실증이 SD v1.x와 특정 공격군에 한정.
NeurIPS 2024 · Bui et al.

Erasing Undesirable Concepts with Adversarial Preservation

여기서 “adversarial”은 공격 prompt가 아닙니다. 삭제 도중 가장 많이 손상되는 남은 개념을 찾아 그 개념을 보존하는 감시자로 사용합니다.

이 논문의 질문

“왜 항상 빈 문자열을 보존하지? 지금 가장 크게 망가지는 개념을 보존해야 하지 않을까?”

방법 flow

  1. target ce를 neutral cn에 맞추는 기본 삭제.
  2. 현재 편집 모델과 원본 모델의 출력 차이가 가장 큰 남은 개념 ca 탐색.
  3. 그 ca의 원본 출력을 보존하는 loss 추가.
  4. Gumbel-Softmax로 discrete 단어 탐색과 gradient 학습을 연결.

핵심 min–max 수식

minθ′ maxca∈R [ ‖εθ′(ce)−εθ(cn)‖² + λ‖εθ′(ca)−εθ(ca)‖² ]

max: 현재 제일 많이 망가진 ca를 찾습니다. min: target은 지우되 그 ca의 차이는 줄입니다.

예: nudity 삭제 뒤 person 차이=8, truck=1, tree=.5라면 ca=person을 보존 loss에 넣습니다.

Contribution

  • neutral anchor가 민감도 스펙트럼의 중간일 뿐이라는 경험적 분석.
  • target마다 달라지는 collateral damage를 adaptive하게 추적.
  • Gumbel-Softmax로 의미 있는 discrete concept를 찾음.
  • 5-object 동시 삭제에서 높은 erasure를 유지하며 preservation 개선.

Limit

  • 논문 명시: 전체 concept space를 넣는 비용이 커 K-nearest 후보로 줄여야 함.
  • Oxford 3000 단어 중심이라 다국어·구문·복잡한 개념 공간은 포괄하지 못함.
  • nudity 삭제는 A100 80GB에서 6시간 미만으로 보고되어 경량 방법은 아님.
  • CLIP/embedding 유사성과 후보군 품질에 민감.
ICLR 2025 · Nie et al.

Erasing Concept Combinations with CoGFD

“kid”, “drink”, “wine” 각각은 보존하면서 kid ∧ drink ∧ wine이라는 조합과 같은 주제의 변형만 약화하는 CCE 문제를 공식화합니다.

이 논문의 질문

“안전한 단어들이 조합되어 위험한 장면이 될 때, 단어를 죽이지 않고 조합만 끊을 수 있을까?”

방법 flow

  1. 하나의 seed 조합을 LLM Generator에게 입력.
  2. ≡, ⊑, ∧ 관계의 concept logic graph를 만들고 Reviewer가 오류 수정.
  3. 같은 theme의 조합들을 뽑아 각 구성 concept으로 분해.
  4. 초기 denoising 구간의 high-level feature는 조합에서 멀게, 개별 concept에서는 원본과 가깝게 학습.

수식이 하는 일

D(Φθ,Φθ̃,p)=Σearly t ‖Φθ(…,p,t)−Φθ̃(…,p,t)‖²L = α·exp(−Dcombo) + (1−α)·exp(ΣDindividual)

L을 줄이려면 Dcombo는 커져야 하고 Dindividual은 작아져야 합니다. 즉, 원본과 조합의 high-level feature는 갈라놓되, kid·wine 각각은 원본에 붙잡아 둡니다.

Contribution

  • Concept Combination Erasing 문제를 명시적으로 공식화.
  • 동일 theme의 여러 표현을 LLM logic graph로 확장.
  • 개별 concept 삭제가 아니라 co-occurring high-level feature를 decouple.
  • HarmfulCmb와 UnlearnCanvas 등에서 조합 삭제/개별 보존을 함께 평가.

Limit

  • 논문 가정: 이미지가 주로 하나의 concept combination과 연관된다고 봄.
  • LLM graph는 불안정하고 크기가 커질수록 오류가 늘어 Generator–Reviewer와 외부 API에 의존.
  • 논문 명시: HarmfulCmb의 고위험 내용이 주로 minors 관련으로 제한.
  • “초기 timestep = high-level feature” 근사와 SD v1.5 중심 실증.
Findings of EMNLP 2025 · Saha et al.

Side Effects of Erasing Concepts from Diffusion Models

새 삭제 방법이 아니라 SEE 평가 benchmark입니다. “car를 지운 뒤 car만 검사”하는 관행이 얼마나 많은 실패를 놓치는지 보여줍니다.

이 논문의 질문

“지웠다는 주장을 계층, 조합, 속성 수준으로 다시 검사하면 무엇이 새어 나올까?”

평가 flow

  1. 11개 superclass 아래 object와 조합 prompt 5,056개 구성.
  2. 크기·색·재질을 붙여 semantic/compositional distance를 만듦.
  3. 각 모델·prompt당 4장, 총 20,224장을 생성.
  4. CLIP 분류와 Qwen/BLIP/Florence VQA로 target·preserve 존재를 검증.

세 가지 side effect

Target Acc = (1/|E|) Σ 1[target이 보임] ↓
Preserve Acc = (1/|P|) Σ 1[preserve가 보임] ↑

① Evasion: vehicle을 지워도 bicycle·large pizza 같은 하위/조합으로 우회.
② Neighbor damage: blue couch를 지우자 blue chair도 사라짐.
③ Attribute leakage: wooden bench를 지우자 wooden이 bird로 이동.

Contribution / Finding

  • 계층·조합 prompt를 포함한 model-agnostic 자동 평가 suite.
  • 8/11 superclass에서 subclass/조합 우회가 80–100% 수준.
  • 편집 후 preserve 대상의 attribute leakage가 모든 평가기에서 50% 이상.
  • 63개 변형을 한 번에 지우는 것보다 순차 삭제가 더 효과적이라는 관찰.

Limit

  • 논문 명시: object/supercategory와 자동 검증 가능한 size·color·material에 제한.
  • 연구가 다룬 세 부작용 외의 실패 모드는 남아 있음.
  • 저자들은 배포가 쉬운 특정 CET 계열 중심 평가라는 범위 제한을 명시.
  • 자동 verifier 자체의 오분류와 문화·맥락적 위험은 별도 문제.
AAAI 2026 · Tu et al.

Mass Concept Erasure with Concept Hierarchy

많은 subtype을 하나씩 지우면 공통 부모인 supertype까지 무너집니다. 의미 계층으로 묶어 지우고, 부모 방향과 직교하는 저랭크 공간에서만 업데이트합니다.

이 논문의 질문

“수십 명의 celebrity를 지우면서 ‘person’ 자체와 저장 비용을 지킬 수 있을까?”

방법 flow

  1. LLM으로 subtype을 supertype별 그룹화: macaw·eagle → bird.
  2. 그룹마다 하나의 파라미터 세트로 attention-based suppression.
  3. mask 밖 영역에는 standard diffusion loss로 denoising 보존.
  4. supertype gradient subspace의 직교 여공간을 B로 고정하고 A만 학습.
  5. 여러 SuPLoRA를 target alignment + generality consistency로 하나에 distill.

SuPLoRA의 기하학

oj = Whj + AjBjhjΔW′A = ΔW′full BjTBj

B가 supertype gradient 공간 Sj와 직교하도록 고정되면, A를 바꿔도 update는 부모 방향을 덜 건드립니다.

2D 비유: “person” 지식이 x축이라면 삭제 업데이트를 y축에서만 허용하는 칸막이입니다.

Contribution

  • mass erasure를 supertype–subtype 계층으로 재구성.
  • concept별 모듈 대신 group별 공유로 parameter 효율 향상.
  • SVD와 gradient orthogonality로 부모 개념 보존을 이론화.
  • object·celebrity·pornography를 동시에 다루는 다중 domain benchmark.
  • ablation에서 7.11MB 대 28.5MB로 더 작은 설정을 보고.

Limit

  • 논문 명시: 공유 supertype 구조가 약하면 group suppression 효과가 낮을 수 있음.
  • 기본 구조는 2-level hierarchy이며 LLM이 만든 grouping 품질에 의존.
  • 부모 subspace를 text embedding/SVD로 근사하므로 실제 시각 개념 전체를 완전히 포착한다는 보장은 없음.
  • 계층 밖의 조합·속성 leakage와 적대적 prompt 강건성은 별도 축.

Glossary

헷갈리는 용어

수식을 읽을 때 이 여섯 개만 기억하면 본문의 대부분을 따라갈 수 있습니다.

ε (noise)
모델이 매 단계 제거하려고 예측하는 노이즈. 실제로는 큰 텐서입니다.
θ / θ*
θ는 학습 중 모델, θ*는 보통 동결한 원본 교사 모델.
Embedding c
텍스트의 의미를 담은 숫자 벡터. 가까운 벡터가 항상 같은 시각 의미를 보장하진 않습니다.
Locality
편집이 target 주변에만 머물고 나머지 능력은 보존되는 성질.
ASR
Attack Success Rate. 공격 prompt가 지운 개념을 되살리는 비율. 낮을수록 좋습니다.
LoRA: AB
큰 W 전체 대신 작은 rank의 A와 B로 update를 표현하는 parameter-efficient 방식.
Supertype / Subtype
bird / macaw처럼 부모–자식 의미 관계. 부모를 지키면서 자식만 지우는 것이 어렵습니다.
Concept combination
각각은 안전할 수 있지만 함께 등장할 때 특정 theme가 되는 개념의 논리곱.
