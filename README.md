# DEMOS_CODEX

AI 에이전트, 코드 지원, 지식 관리 및 웹 인터페이스 프로젝트의 소스 모음입니다.

| 경로 | 구성 |
| --- | --- |
| `app.py`, `demos_v1/` | 메인 데모 애플리케이션과 API 라우트 |
| `code_assist_v1/` | 코드 지원, 지식 관리, Notion 및 에이전트 연동 |
| `harness-mvp/` | 에이전트 하네스와 테스트 |
| `hermes-web/` | Hermes 웹 인터페이스 |
| `rendering/` | 렌더링 웹 애플리케이션 |
| `scientific-skills/`, `지식베이스/` | 스킬 및 지식 도구 소스 |
| `llm-wiki/`, `concept-erasure-paper-guide/` | 문서와 웹 가이드 |
| `beno/`, `uio/` | 웹 페이지 프로젝트 |

실행 방법은 각 하위 프로젝트의 README와 기존 문서를 참고하세요.
API 설정이 필요한 프로젝트는 `api_config.example.json`을 같은 위치의 `api_config.json`으로 복사한 뒤 본인 환경의 설정과 인증 정보를 입력하세요.

이 공개 저장소에는 소스와 개발 문서를 포함합니다. 로컬 인증 정보, 사용자 데이터, 대화 이력, 실행 로그, 가상 환경, 모델 파일과 생성 결과물은 포함하지 않습니다.

## 최신 Second Brain 소스

`code_assist_v1/`에는 2026-10-12 기준 10521 서버에서 사용 중인 소스를 반영했습니다. 기존 프로젝트의 다른 구성은 유지하고, 최신 문서 추출·Wiki 작성·인용·입력 토큰 예산 처리와 해당 테스트 및 오프라인 UI 라이브러리를 포함했습니다.

실행 계정, API 설정, 사용자 문서·대화, 데이터베이스, 배포용 활성화 파일 및 실제 화면 캡처는 공개 저장소에 포함하지 않습니다. 로컬 서버를 복제해 자동으로 실행하는 배포 패키지는 아닙니다.
