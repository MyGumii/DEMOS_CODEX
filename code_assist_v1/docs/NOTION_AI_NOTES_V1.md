# AI 노트 v1 — 2026-09-11

사용자 요청에 따른 신규 기능. 기존 V0R/NP-1B 완료 증거나 SBE 계약을
수정하거나 이 기능의 증거로 재사용하지 않는다. 전체 제품/Z0 완료 선언이 아니다.

## 사용

Notion 페이지에서 `/회의` 또는 `/AI` → **AI 노트**를 선택한다.
원문에 회의록을 붙여넣거나 UTF-8 텍스트 파일(txt/md/vtt/srt)을 가져온다.
메모에는 안건·배경·직접 작성한 기록을 넣는다. 요약 설정에서 모델과
추가 지침을 선택한 뒤 **요약 생성**을 누른다.

요약, 결정 사항, 담당자·기한이 있는 할 일과 원문 근거가 표시된다.
`근거`는 원문/메모의 해당 구절을 선택한다. 할 일 완료 상태도 저장한다.
원문 변경 시 기존 요약은 보존하고 재생성이 필요하다고 표시한다.
AI 초안은 검토 대상이며, 근거 인용 검사는 요약 전체의 사실성을 보증하지 않는다.

## 모델 연결

기존 서버 모델 레지스트리 및 `internal_llm` 호출 경로를 재사용한다.
Gemma4와 Qwen3.6은 각각 실제 제공 서버의 정확한 `model` 값과
chat-completions URL/인증 설정으로 등록하면 선택 목록에 나타난다.
모델 이름으로 음성 기능을 추측하지 않는다. 클라이언트에서 임의 URL,
토큰이나 등록되지 않은 모델을 전달할 수 없다. API 비밀값을 브라우저에 보내지 않는다.

자동 선택은 기존 API → GGUF → (허용된 경우) Codex 순서를 따른다.
명시적 모델 선택은 그 모델만 호출한다. 최대 3회 모델 시도, API 시도당 90초,
Codex 시도당 180초, 요청 본문 400,000바이트 한도이다.
Codex는 기존 `--codex` 시작 정책을 따르며 이 변경에서 활성화하거나
Codex bridge/공통 모델 호출 코드·설정·작업공간 권한을 변경하지 않는다.
Codex도 텍스트 요약 경로이며 녹음/음성 전사를 수행하지 않는다.

후속 음성 입력·회의 중 요약 추가는 [AUDIO_V2](NOTION_AI_NOTES_AUDIO_V2.md)를 참조한다.
아래는 v1 출시 시점의 범위와 검증 기록이다.

현재 v1은 **텍스트 기반**이다. 마이크 녹음, 시스템 오디오 캡처,
오디오 파일 업로드·STT, 실시간 전사, 화자 자동 식별은 포함하지 않는다.
실제 음성 API의 요청/응답 계약이 확보된 뒤 별도 연결이 필요하다.
Gemma4/Qwen3.6 실제 회사 API의 추론 품질·음성 지원은 아직 검증하지 않았다.

## API 계약 (독립 registrar)

`app_notion.create_app`이 `register_notion_ai_notes_routes`를 별도로 등록한다.
기존 NP-1B의 59개 legacy/bridge 라우트 등록 함수·목록·검증은 그대로 둔다.

* `GET /api/notion/ai-notes/capabilities`: 인증 필요. 공개 모델 ID/이름/provider,
  입력 한도, `audio_transcription: false`를 반환한다.
* `POST /api/notion/ai-notes/summarize`: 인증과 페이지 편집 권한 필요.
  `page_id`, 협업 모드의 `workspace_id`, `transcript`(80,000자),
  `notes`(12,000자), `instructions`(2,000자), `model_id`(빈 값은 자동)를 받는다.
  `status: draft`, `result`, 실제 모델 메타데이터와 `source_sha256`를 반환한다.
  읽기/댓글 전용·잠금 페이지는 거부한다. 권한을 전송 전/시도 경계/결과 반환 전에
  재검증한다. 협업 모드에서 legacy DB 권한으로 우회하지 않는다.
* 전체 HTTP 요청 최대 512,000바이트, 프로세스당 동시 생성 2개. 초과는 413/429.
* 입력 오류 400, 미인증 401, 권한 없음 403/404, 모델 실패·잘못된 출력 503.
  upstream URL·토큰·응답 본문은 오류 메시지에 노출하지 않는다.
* 모든 응답은 `Cache-Control: no-store`. 생성 API는 DB에 쓰지 않는다.
  클라이언트가 기존 페이지 저장/협업 편집 경로로 결과를 저장한다.

## 저장·격리

`ai_notes` 블록의 props에 원문·메모·지침·요약·완료 상태를 저장한다.
content에는 원문/요약을 포함한 읽을 수 있는 Markdown을 유지하므로 기존
검색·내보내기·Second Brain 게시가 내용을 읽을 수 있다.
페이지 공유 권한을 그대로 상속한다. 새 공유·알림·계정·멤버십은 만들지 않는다.
타 페이지를 검색하거나 관련 페이지를 모델 프롬프트에 추가하지 않는다.
모델 오류를 가짜 성공 요약으로 대체하지 않는다.
생성 전에 원문 저장을 확인하고, 입력 변경/페이지 이동/블록 삭제 후 도착한
응답은 적용하지 않는다. 완료 상태와 원문은 새로고침·사이드 보기에서 유지된다.
