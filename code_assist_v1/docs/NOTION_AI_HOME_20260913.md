# Notion 중앙 AI 홈 — 2026-09-13

## 요청과 구현 범위

실제 Chrome의 `https://app.notion.com/ai`에서 관찰한 중앙 입력창,
왼쪽 채팅/새 채팅, 생성 작업 카드를 기준으로 독립 AI 홈을 추가했다.
기존 오른쪽 문서 AI만 제공하던 화면과 구분된다.

- 왼쪽 **AI 채팅** 또는 **채팅**, 하단 **새 채팅**, `Ctrl+O`로 연다.
- `/ai`는 새 대화, `/ai/<chat_id>`는 저장된 대화다. 새로고침과 기록 복원을 지원한다.
- 왼쪽 대화 기록에 제목을 표시하고, 대화 보관/복원과 더 불러오기를 제공한다.
- 본인이 읽을 수 있는 Notion 페이지 최대 4개와 본인 Second Brain 개인 Wiki 1개를 명시적으로 선택한다.
- 대화의 참고 범위는 불변이다. 선택을 변경하면 이전 대화는 보존하고 새 대화를 시작한다.
- 페이지 선택이 없으면 현재 열었던 페이지를 몰래 첨부하지 않는다. 일반 대화로 동작한다.
- 모델 출력의 제목/목록/강조/코드 블록을 DOM으로 표시한다. 원시 HTML, 스크립트, 모델 URL은 실행하지 않는다.
- 기존 문서 AI는 페이지 상단 **문서 AI**, 선택 문장/블록 AI에서 유지한다.
- 사이드바 하단의 **Second Brain 템플릿 만들기**는 복구하지 않았다.

## 실제 연결된 작업

| 카드 | 수행 내용 | 내보내기 | 한계 |
| --- | --- | --- | --- |
| 채팅 | 일반 질문 또는 명시적으로 선택한 자료 기반 대화 | Markdown | 작업 실행/자동 문서 수정 없음 |
| 슬라이드 생성 | 제목과 핵심 항목으로 구성된 1–12장 미리보기 | 독립 HTML 슬라이드 | PPTX 아님 |
| 스프레드시트 | 1–16열, 1–200행의 구조화된 표 | UTF-8 BOM CSV | XLSX/실행 가능한 수식 아님 |
| 자료 리서치 | 선택한 페이지·개인 Wiki 검색 결과를 출처와 함께 정리 | Markdown | 웹 전체 검색/심층 리서치 아님 |
| 시각화하기 | 최대 16개 범주의 양수·음수 막대차트 | SVG | 임의 코드/차트 종류 생성 아님 |

각 카드에는 위 형식과 제한을 화면에 표시한다. LLM이 반환한 구조와 출처를
검증한 뒤 미리보기/다운로드를 제공한다. CSV의 수식처럼 해석될 수 있는 문자열은
작은따옴표로 중립화하며, 숫자 자료의 음수는 숫자로 유지한다. HTML/SVG는
호스트가 검증된 데이터에서 생성한다. 파일은 응답 스트림으로 내려주며 자동으로
공유 폴더나 사용자 문서에 쓰지 않는다. 사용자가 다운로드한 파일은 사용자가 관리한다.

## 저장과 권한

- 새 저장소: `USER_DATA_DIR/<user_id>/notion_ai/chats.db`.
- 기존 Notion 페이지 DB, SBE canonical DB/schema, 개인 Wiki 원본에는 쓰지 않는다.
- 대화 제목, 범위, 본문, 생성 결과는 사용자 ID와 지속적인 호스트 secret으로
  파생한 Fernet 키로 암호화한다. ID/시간/상태/요청 해시는 운영 메타데이터다.
- **백업 시 호스트 secret도 안전하게 보존해야 한다.** secret 변경이나 유실 시
  기존 대화는 복호화되지 않으며 자동 초기화하거나 덮어쓰지 않는다.
- 읽기만으로 없는 사용자 저장소를 만들지 않는다. 새 대화 생성 때 별도 저장소를 만든다.
- 최대 500개 대화/대화당 50턴(100개 메시지), 암호화 전 payload 최대 4 MB.
  자동 삭제/영구 purge는 없다. 보관은 복원 가능하며 보관 한도를 줄이지 않는다.
- 같은 작업 ID와 동일 요청은 재실행하지 않는다. 다른 내용으로 ID를 재사용하면 409다.
- SQLite 트랜잭션 내 claim으로 프로세스 간 중복 생성을 막는다. LLM 호출은
  DB 트랜잭션 밖에서 수행하며, 600초 claim 만료 후 이전 요청 ID의 자동 재실행은 금지한다.
- 브라우저 새로고침은 생성 중 상태를 조회한다. 모델 요청을 다시 보내지 않는다.
  실패/만료는 중단 상태로 알리고, 사용자가 새 요청으로 재시도한다.
- 계정/워크스페이스/페이지/Wiki 권한을 조회·생성 직전·모델 시도 전후·저장 직전에
  재확인한다. 생성 중 원문 변경/권한 회수는 fallback으로 우회하지 않는다.
- 권한을 잃은 자료를 포함한 대화는 목록 제목, 본문, 다운로드에서 숨긴다.
  Wiki의 기존 인용 revision이 더 이상 유효하지 않은 경우에도 보수적으로 차단한다.
  이 경우 기존 기록을 변형하지 않고 현재 권한/자료로 새 대화를 시작한다.
- 페이지 본문과 Wiki 발췌의 합계는 정확히 96 KiB 이하다. 초과 시 UTF-8 경계를
  지켜 잘라내고 화면에 생략 사실을 표시한다. 임의 props/첨부파일/인접 페이지는 포함하지 않는다.
- 회의의 host-only 비교 요약 저장소는 읽지도, 채팅에 노출하지도 않는다.
