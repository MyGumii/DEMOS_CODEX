# AI 노트 내용 비우기 · 2026-09-11

사용자 요청: 원문·요약·메모 등에 clear 기능 추가.

## 사용자 동작

- 각 탭에 `원문 비우기`, `요약 비우기`, `메모 비우기` 버튼을 제공한다.
- 하단의 `전체 내용 비우기`는 해당 AI 노트의 원문·메모·요약·결정·할 일을 비운다.
- 모든 비우기는 범위를 설명하는 확인창을 거친다. 취소하면 변경하지 않는다.
- 원문/메모만 비우면 다른 내용과 기존 요약은 남긴다. 요약의 source key 비교에
  따라 이전 요약 안내가 표시된다.
- 요약 비우기는 요약 본문, 결정 사항, 할 일과 생성 메타데이터를 함께 제거한다.
- 전체 비우기에도 모델 선택, 출력 언어, 요약 지침, 노트 버전 및 무관한 설정은
  유지한다. 다른 블록/페이지는 대상이 아니다.
- 빈 항목은 비활성화한다. 공백만 입력된 원문/메모도 비울 수 있다.
- 변경은 기존 페이지 편집/저장 경로를 사용한다. 저장 실패는 성공으로 표시하지
  않으며 새로고침 전에 페이지 저장 상태를 확인하도록 안내한다.

## 안전 및 동시 처리

- 편집 권한이 있는 사용자에게만 표시하고, 확인창 후에도 현재 페이지/블록과
  편집 권한을 다시 확인한다. 읽기 전용 다운로드 기능은 유지한다.
- 녹음 시작·진행·일시정지·종료, 전사 대기/오류 큐, 요약 처리, 텍스트 파일 읽기,
  비우기 저장 중에는 비우기를 차단한다. 버튼 표시뿐 아니라 실행 핸들러도 검사한다.
- 비우기 저장 중 새 녹음/음성 가져오기/요약 생성을 시작하지 않는다.
- 비우기는 AI 생성을 요청하지 않으며 음성 큐를 삭제하거나 다른 작업을 중단하지
  않는다. 메인 및 사이드 페이지의 기존 저장 계약을 사용한다.
- 이것은 편집 가능한 현재 노트 내용의 초기화이며, 저장된 과거 버전·백업·이미
  다운로드된 파일을 영구 삭제하는 purge 기능이 아니다. 별도 복구 버튼은 이번
  범위에 포함하지 않으며 필요한 내용은 먼저 다운로드하도록 확인창에서 안내한다.
