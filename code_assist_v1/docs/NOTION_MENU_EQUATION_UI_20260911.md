## 구현

- 메뉴: 지원 항목을 실제 상대 순서대로 그룹화. `표`와 데이터베이스 `표 보기`
  구분, `리스트 보기`, `수학 공식 블록`, `이동 경로`, 토글 제목 명칭 교정.
  추천의 AI 노트/HTML 중복 진입점도 유지한다. 원본 자산 추출 없이 직접 작성한
  선형 SVG 아이콘을 사용하며 픽셀 완전 일치를 주장하지 않는다.
- 검색: 초기 검색어가 있어도 전체 항목을 보존하여 지웠을 때 복구한다.
  영어 키워드·한글 띄어쓰기 검색, 빈 결과, 방향키/Enter/Escape,
  IME 조합 중 Enter의 오작동 방지를 검증한다. 닫기 버튼은 고정하고 목록만 스크롤한다.
- 수식: 평상시에는 렌더링만 표시한다. 클릭 또는 Ctrl/Cmd+Enter로 약 400px
  임시 팝업을 열고 `완료`, Enter, Escape, 바깥 클릭/포커스 이동으로 닫는다.
  Shift+Enter는 줄바꿈. `\alpha`, `$\alpha$`, `$$\alpha$$`, 분수·다중 행을
  기존 로컬 KaTeX로 렌더링하고 원본 LaTeX만 저장한다. 잘못된 수식의 오류도 표시한다.
  메인·사이드 보기, 읽기 전용, 페이지 전환 시 오래된 팝업 차단을 포함한다.
- HTML: 기존 `embed` 블록에 `props.embed_mode="html"` 및 원본 source `content`를
  저장한다. 소스 입력/200 KB 이하 HTML 파일 선택, 완료 후 미리보기, 재편집을 제공한다.
  미리보기는 opaque-origin `sandbox=""` iframe이며 스크립트·외부 통신·폼·링크 이동을
  차단한다. **정적 HTML/CSS 전용**이다. AI HTML 생성이나 외부 스크립트 실행을
  구현했다고 주장하지 않는다. 기존 일반 URL 임베드 동작은 바꾸지 않았다.
- 4·5열: 기존 레이아웃 props를 사용하여 생성·렌더링·저장·재로드 지원.
- 오른쪽 목차: 마우스 클릭으로 이동한 뒤 포커스를 해제하여 마우스가 떠나면 접힌다.
  키보드 이동·활성화 때에는 포커스를 유지한다.
