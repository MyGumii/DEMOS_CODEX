## Implemented contract

The public command is:

```powershell
.\venv\Scripts\python.exe -m code_assist_v1.tools.legacy_inventory inventory `
  --legacy-root C:\frozen\code_assist_v1 `
  --knowledge-root C:\frozen\knowledge `
  --snapshot-id SNAPSHOT_OR_VSS_ID `
  --output C:\migration\inventory.json
```

`--knowledge-root` is repeatable. Runtime, user-data, sessions, and workspace
roots may be supplied explicitly; otherwise existing legacy children are
derived. Automated tests use only P0.2-isolated temporary roots.

The implementation proves the following behavior:

- Forty-one fixed categories are present even when empty. File and logical
  record counts, bytes, raw SHA-256 values, category aggregates, relationships,
  exclusions, limitations, source roots, and high-water hashes are emitted in
  deterministic canonical JSON.
- The scanner imports no application config, app, auth, or legacy store module.
  It never creates source roots, schemas, or sidecars and never displays source
  document bodies, credentials, exception text, session payloads, graph endpoint
  IDs, or candidate text.
- User-directory ownership is confirmed only against `.runtime/users.json`.
  A directory name is a claim, not authority: an absent registry owner is
  recorded as `unresolved_path_owner`, quarantined, and reported as a missing
  reference.
- Canonical Markdown, hidden pages, graph nodes/edges, candidates, assets,
  derived index/log/backlinks, flat legacy raw/thought/inbox/raw-chunk/edge/
  tombstone data, sessions, memory, project context, jobs, Notion, Outlook
  state, server logs, and recovery candidates are separately classified.
- Graph inventory counts valid, legacy-auto, duplicate, and orphan edges.
  Legacy JSONL edges and candidate evidence are retained only as allowlisted
  metadata and hashes. Semantic or unknown relation text is not exposed.
- Session messages, metadata, summaries, uploads, and bindings become
  deterministic hash-only logical children, so equal counts with different
  payloads do not reconcile falsely.
- Queued/running legacy jobs are labelled `abandoned_legacy` and are never
  represented as replayable durable jobs. Source job-state counts remain in the
  report.
- The source Notion SQLite database is never opened. The DB and any WAL, SHM,
  or journal are byte-copied to a scanner-owned temporary directory with source
  hashes checked before and after; only the copy is opened with `mode=ro` and
  `query_only=ON`. Live sidecars are retained separately from backup candidates.
- Every Windows reparse attribute is rejected, including tags that are neither
  a symlink nor a junction. UNC, non-local roots, root aliases, overlapping
  physical roots, normalized path collisions, and output-inside-source aliases
  fail closed.
- `--allow-partial` relaxes only record-level data-quality errors. Invalid roots,
  code-coverage failure, source drift, path collisions, reparse entries, and an
  inconsistent SQLite snapshot still exit 2. Output infrastructure failures
  exit 3.
- Output is one UTF-8 canonical JSON object on stdout or an atomic file replace.
  Existing output requires explicit `--replace-output`.
