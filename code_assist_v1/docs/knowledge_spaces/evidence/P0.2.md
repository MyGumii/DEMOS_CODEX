  path-caching application/store import.
- Relative roots, filesystem roots, regular files, repository/package roots,
  live mutable roots, overlapping parents/children, and resolved link/reparse
  escapes are rejected before writes.
- The pytest bootstrap validates inherited temporary-directory candidates
  before creating its session directory.
- Effective secrets, external-process switches, temporary paths, API config,
  Outlook key paths, and loaded store paths are checked before and after every
  test.
- Tests exercise a real Windows directory junction escaping a guarded root,
  not only a mocked path.
- SQLite, blob, projection, and Notion fixtures are created only below the
  guarded per-test layout and explicitly cleaned up.
