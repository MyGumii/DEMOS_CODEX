## Frozen fault and scale boundary

- `migration.before_checkpoint` is invoked inside the service-owned database
  transaction immediately before every new immutable record or relationship
  checkpoint in the P2.3 identity/content, P2.4 graph/history, and P2.5
  session/Notion/job importers. An injected exception rolls back both the
  canonical effect and checkpoint.
- `migration.after_batch_commit` is invoked by the top-level apply service only
  after a service-owned batch has returned from its committed transaction. A
  hard process exit at this boundary can expose only a complete durable prefix.
- The process-death test exits a real child Python process with code 73 after
  the first committed identity batch. The database contains exactly two
  identity mappings and zero items. Restart inserts the remaining three
  mappings and strict verification reports zero unresolved records and
  relationships.
- The large fixture creates 205 ordinary Markdown files plus one nested Unicode
  file whose absolute Windows path is longer than 260 characters. Inventory,
  planning, apply, and verification succeed. Its 206 personal-item records are
  committed in exactly three content batches, with no batch exceeding 100.
- Windows extended-path spelling is used only near the traditional path limit.
  Canonical relative paths and public source identities remain normalized,
  prefix-free values; ordinary path instrumentation and enumeration-denial
  behavior remain unchanged.
- The dirty fixture includes duplicate and orphan relationships, an unavailable
  missing-asset target, and a `.md.tmp` recovery near-miss. Every inventory
  record and relationship appears once in the verification report, quarantine
  mappings remain absent, and both unresolved counters are zero.
- Exact replay creates zero new mappings, produces the same verification
  artifact, and leaves every canonical table count unchanged. Imported
  knowledge appears only in personal spaces; unowned global sessions require
  an explicit quarantine decision and no part space or part item is created.
- Rebuild-classified records have no import checkpoint and are observed as
  `rebuilt`; legacy index/backlink data is never accepted as canonical truth.
