# P3.7 canonical browser/API/Agent isolation evidence

Date: 2026-08-14 (Asia/Seoul)

## Result

P3.7 and the tested P3/G-07 implementation gate pass behind the disabled
canonical-traffic boundary. The canonical browser transport, Flask routes,
conversation services, one-space management reads, SSE turn execution, and
Agent context now form one server-authorized path. The default flag-off host
and legacy UI path remain unchanged.

This evidence does **not** enable a feature flag, redirect production traffic,
start a worker, access or mutate live data, run migration, or enable part
writes/publication. Operational cutover remains a later explicitly approved
action.

## Frozen behavior

- The canonical Flask group has 17 strict `/api/knowledge/v1/...` routes for
  scope options, conversation lifecycle, SSE/reconnect, compact, pins/context,
  and one-space list/search/graph/projection/activity/finding reads. It
  registers only through explicit composition and rejects incomplete service
  bindings before adding a route.
- Actor ID and captured scope epoch come only from the injected server
  principal. Browser payloads never select an actor or authorize a space.
- Conversation space is immutable. Personal/current-part options are resolved
  from current canonical state; stale epochs, former parts, foreign spaces,
  cross-space endpoints, and inaccessible conversations fail closed.
- Browser activation requires a successful canonical scope probe. Active mode
  uses only the canonical prefix for chat, sessions, SSE, selector, and seven
  management surfaces and returns before any legacy transport is invoked.
- Lazy conversation creation and turn retry preserve one operation ID across
  unknown outcomes and coalesce concurrent identical work. SSE decoding checks
  monotonic sequence, event/body identity, operation/request/turn UUIDs,
  exactly one terminal event, and absence of post-terminal data.
- Canonical sessions list/load/rename/archive/compact server state. Archive is
  used instead of destructive browser deletion. Successful turns reload the
  canonical conversation before rendering the assistant message.
- Injected core mode does not import or register legacy knowledge, Second
  Brain, memory, project-context, chat-stream, session, or agent-harness route
  modules. The canonical Agent path performs one conversation-derived
  retrieval and has no implicit private/default-project context.
- Activity is a read-only canonical management surface with exact space,
  cursor, item/revision, and actor coherence. It exposes only sanitized event
  fields and never raw audit details, request metadata, or numeric DB IDs.
