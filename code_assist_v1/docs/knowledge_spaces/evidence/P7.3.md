# P7.3 outbox materializer evidence

Date: 2026-08-15 (Asia/Seoul)

## Result

P7.3 passes its P0.2-isolated, disabled-worker/traffic implementation boundary.
Canonical generation, durable outbox insertion, and desired projection state
commit or roll back together. An explicit leased worker writes one complete,
checksum-bound immutable space generation and acknowledges only a manifest that
still matches current canonical state. Full and settled incremental checksums
match, while Agent retrieval remains canonical DB/FTS during lag.

This is not the aggregate P7, `G-10`, `G-11`, deployment, performance, backup,
or restore gate. P7.4-P7.9 retain those responsibilities. No projector/service,
route traffic, feature flag, live root, or live database was started, enabled,
or accessed.

## Durable outbox and desired-generation contract

- `OutboxRepository.append()` preserves logical-key exact replay and, for a
  space-bound event, inserts or advances the Markdown projection's desired
  generation from the current canonical space row in the same transaction.
  Desired state never moves backwards and built state cannot exceed canonical.
- Durable states are `pending | processing | retry | applied | dead`. Claim,
  renew, ack, retry, and expiry recovery require the exact event, owner, attempt,
  and unexpired lease. Attempts are bounded and stored errors are finite,
  canonical, sanitized JSON.
- `OutboxProjectionWorker` is explicit: import and construction start nothing;
  `run_once()` handles at most one event and `serve(stop)` uses bounded,
  stop-aware idle backoff. A non-daemon heartbeat renews below one third of the
  lease.
- Events without a space are explicit applied projection no-ops. Space events
  rebuild from canonical state, never from event payload bodies or legacy files.

## Immutable generation and acknowledgement contract

- One read-consistent selected-space snapshot produces Markdown sources,
  `index.md`, `log.md`, `graph/graph.json`, and `graph/backlinks.json`.
- Body bytes, graph endpoints, activity rows, each file entry, the generation
  aggregate, and `manifest.json` are deterministically hashed. The completed
  generation is pinned and verified before only the small manifest is atomically
  replaced.
- `log.md` includes an exact allowlist tied to the seven live canonical
  generation-writer repositories. Lease, conversation, preview, finding-only,
  and other non-file audit rows cannot alter an existing numeric generation.
  A permanent source scan fails if another live generation-writer module is
  introduced without an assigned projected action.
- Ack occurs in a transaction only when space generation equals desired equals
  built, status is `ready`, checksum is present, and the durable claim fence is
  still live. A canonical advance after manifest replacement retries; the latest
  generation then settles. An older failed/dead row cannot poison a newer ready
  generation.
- Full rebuild and settled incremental rebuild produce the same result and
  manifest bytes. Canonical retrieval and compatibility DB views remain the
  fallback; mixed file generations are never combined.

## Crash and concurrency proof

- A real spawned Windows process exits with `os._exit(73)` after manifest/state
  publication but before ack. A replacement waits for lease expiry, recovers the
  row, and applies it on attempt two with one immutable generation and identical
  manifest bytes.
- Two actual projector processes race one row; exactly one applies it and the
  other observes idle. The durable attempt count remains one.
- Unit fault seams separately prove in-process crash replay, heartbeat renewal,
  stale-owner rejection, expired recovery, bounded dead transition, canonical
  advance in the manifest/ack gap, latest-state preservation, and private error
  sentinel exclusion.

## Safety and deliberate limits

- No worker loop, Windows service, WSGI host, model, feature flag, route traffic,
  live data root, canonical live database, or external service was started.
- This task does not configure service accounts/ACLs/start order, target-server
  storage, backup/restore, health endpoints, randomized kill profiles, or
  forty-client performance. Those remain P7.4-P7.9.
- Numeric generation directories are immutable and may remain after a failed
  pre-manifest attempt; they are safe checksum-identical staging artifacts, not
  authority. `manifest.json` plus canonical projection state is the reader
  boundary.
- The projector treats no-space outbox events as explicit no-ops because the
  same durable table also carries non-projection account/system evidence.
- P7.3 does not authorize part writes or cutover and does not close aggregate
  P7, `G-10`, or `G-11` beyond the named `PROJ-001..006` disabled
  implementation evidence.
