This file records only the implementation and isolated verification of the
`PERF-001` load harness. It is deliberately not named `P7.8.md`: no target

traffic, worker, feature flag, live root, or live database was accessed or

is archived.

## Frozen boundary

- The runner requires the exact five profile configurations, 40 clients, one
  fixed seed, explicit `PERF-001_TARGET_LOAD`, and distinct HTTPS Web/Notion
  origins. A wrong or absent confirmation stops before the credential file is
  read or any request is sent; `--validate-only` remains network-free.
- Both production WSGI health endpoints must be ready and share the exact
  build/config/catalog/migration/SQLite binding before authentication. Web
  health is sampled during the run; both services are checked after cooldown.
- The canonical fixture contains four ten-client parts, one hot item per part,
  40 distinct saturation targets, and every directed pair in the 40x39
  personal-canary matrix (1,560 leak cases, each used by five leak surfaces).
- Reports preserve raw JSON/CSV samples, nearest-rank p50/p95/p99, busy/error/
  canary counts, projection lag, queue peaks/final state, health observations,
  hardware, build/schema/SQLite identity, seed, and fixture/client hashes.
  Dedicated invariant samples record stale-save revision stability, complete
  dual publication, terminal/recoverable jobs, and at-most-one domain effect;
  all required checks must be observed with zero failures.
- The independent report verifier recomputes CSV bytes, samples, summary,
  fixture/sample binding, hardware binding, and report hash. The gate binder
  accepts exactly one report for each profile and rejects target, fixture,
  seed, hardware, build, schema, SQLite, duplicate-run, or duplicate-report
  drift.
- Windows input reads are parent/file identity-bound. Evidence creation uses a
  fixed-local-NTFS non-reparse pinned parent, handle-relative create, and a
  delete-pending handle while bytes are written; existing outputs are never
  overwritten.

The exact operational contract and commands are in
`tests/knowledge_spaces/load/README.md`.
