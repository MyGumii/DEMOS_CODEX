10322에 반영했다. 로컬 Qwen과 자체 SearXNG를 그대로 사용한다.

## 확인한 문제

admin의 `49c365dc-6322-4ce0-bc38-c12936d51db0` 대화는 실제 웹 자료 네 개를 수집했지만, GAT와 무관한 논문이 섞여 있었다. 일반 채팅은 인용 배열을 생성하지 않았고, 슬라이드·스프레드시트·시각화의 프롬프트와 JSON 문법은 인용을 빈 배열로 제한했다. 검색 결과 목록만 보여 주어 실제 사용한 근거를 구분하기 어려웠다.

## 실제 Notion 비교

로그인한 Chrome에서 일반 채팅으로 GAT 원 논문의 제목·연도·웹 출처를 요청했다. 검색 과정에 `Graph Attention Networks original paper title publication year`가 표시됐고 답변에는 arXiv 인용 링크가 붙었다. 생성 모드 프리셋도 같은 Agent 작성창에 있다. 검색은 자료 리서치에만 한정되지 않는다.

- [Agent의 검색과 파일 생성](https://www.notion.com/help/notion-agent)
- [자료 리서치의 다단계 조사](https://www.notion.com/help/research-mode)

이번 변경은 웹 검색에 대한 정합성이다. 실제 Notion에서 웹 브라우징 승인을 켜지 않은 일반 채팅도 공개 검색을 실행했다.

## 구현

- 웹 켜짐은 다섯 모드에 공통으로 적용한다. 일반 요청도 공개 검색 계획을 만든다. 인사·단순 편집·내 페이지 목록 질문처럼 외부 근거가 필요 없으면 검색을 생략한다.
- 공개 계획과 관련성 판단에는 현재 요청과 공개 결과만 전달한다. 개인 페이지, DB 목록, 이전 대화는 공개 검색어를 만드는 입력에서 제외한다.
- 짧은 논문 제목·핵심 용어를 구문 검색한다. 과학 검색엔진이 `original paper`, `title`, `year` 같은 일반 단어를 폭넓게 매칭하는 경우를 보정한다. 계획 실패 시에도 현재 요청에서 명시한 핵심 용어로 검색한다.
- 일반 모드에서 최대 두 검색을 실행한다. 각 결과는 요청 전체가 아니라 해당 검색 항목을 뒷받침하는지 판단한다. 모델은 반환된 후보의 인덱스만 고를 수 있고 URL을 만들어 실행할 수 없다.
- 관련 자료 본문을 읽고 원문 인용 선택지를 만든다. 문서 제목·탐색 문구만 있는 자료는 답변 근거로 채택하지 않는다. 초록이 있는 자료는 실제 초록 문장부터 인용 선택지를 제공한다.
- 일반 채팅은 자연어 토큰 스트리밍을 유지한다. 호스트가 번호를 부여한 원문 인용만 최종 클릭 가능한 출처로 변환한다. 웹 자료를 공급한 답변은 검증된 웹 인용을 포함해야 한다.
- 생성 모드도 실제 웹 인용을 출력할 수 있게 했다. JSON 원문 인용 쌍과 아티팩트 형식은 계속 검증한다.
- 화면에서 실제 인용한 출처, 검색한 웹 자료, 검색어·결과·관련 자료 수, 실패·근거 부족 상태를 구분한다. 같은 문서를 여러 번 인용해도 출처 개수는 중복 집계하지 않는다.
- 기존 계정·페이지 권한, 응답 저장 전 재검증, 재시도·중복 요청 검증을 유지한다. 관리자에 대한 별도 검색 우회는 없다.

## 검증

최종 Python 관련 테스트 137개, JavaScript 테스트 29개와 구문 검사를 통과했다. 별도 심층 리서치 회귀 테스트를 포함한 이전 실행도 통과했다. 모든 자동 쓰기 테스트와 실제 생성 요청은 OS Temp에 격리한 계정을 사용했다.

실제 Qwen·SearXNG 요청으로 채팅·슬라이드·비교표·시각화의 검색, 최종 저장, 웹 인용을 확인했다. GAT/GATv2 비교표는 두 원 논문을 각각 검색했고, 시각화는 arXiv 최초 발표 연도 2017/2021로 생성됐다. 인사 요청은 웹을 켜도 검색을 실행하지 않았다. Chrome에서 다섯 모드 선택 시 웹 설정 유지와 실제 결과 화면의 인용 링크도 확인했다.

일반 사용자 `ui-member`도 실제 Qwen·SearXNG로 웹 검색과 인용을 생성했다. 해당 계정 소유의 페이지만 내부 출처로 제공되는지 검사했고, admin 대화 조회는 404로 차단됐다. 결과는 `member-chat-summary.json`에 저장했다.

자료 리서치는 기존 내구성 작업의 장별 검색·본문 분석 경로를 사용한다. 이번 검증에서 별도의 장시간 전체 심층 보고서를 새로 완성하지는 않았다. 10322에서 이미 진행 중이던 admin 리서치 두 개는 배포 후 체크포인트에서 오류 없이 이어 진행 중임을 읽기 전용으로 확인했다.
