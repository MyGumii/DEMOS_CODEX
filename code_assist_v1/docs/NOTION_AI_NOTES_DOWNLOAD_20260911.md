# AI 노트 텍스트 다운로드 · 2026-09-11

사용자 요청: AI 노트의 원문·요약 등을 파일로 다운로드할 수 있게 한다.

## 구현

- AI 노트 상단에서 전체 노트 / 원문 / 요약·결정·할 일 / 메모를 선택한다.
- TXT 또는 Markdown 형식으로 브라우저 다운로드를 요청한다.
- 원문·메모 TXT는 현재 문자열의 공백, 줄바꿈, 시각 표시를 그대로 보존한다.
  모든 파일은 Windows 한글 인식을 위한 UTF-8 BOM을 포함한다.
- 요약에는 결정 사항, 할 일의 완료 상태·담당·기한·근거를 포함한다.
  전체 노트에는 요약과 메모, 원문을 함께 포함한다.
- 잠정 요약과 생성 후 입력이 변경된 이전 요약에는 안내를 함께 내보낸다.
- 선택한 내용이 없으면 다운로드 버튼을 비활성화한다.
- 녹음·전사·요약 중에는 클릭 시점까지 반영된 내용을 내려받는다. 미전사 음성이나
  아직 반환되지 않은 요약은 파일에 포함하지 않으며 진행 중 처리를 중단하지 않는다.
- 메인/사이드 페이지에서 지원한다. 읽기 전용 사용자도 이미 표시된 노트를 내려받는다.

## 경계

- 브라우저의 현재 블록 내용으로 Blob 파일을 생성한다. 다운로드 동작 자체는
  AI 호출, 원문 추가 전송, 새 서버 조회 또는 페이지 저장을 실행하지 않는다.
  기존 자동 저장·녹음·요약 처리는 독립적으로 계속될 수 있다.
- 요약 지침, 모델/provider 메타데이터, 내부 source key는 내보내지 않는다.
- Markdown의 원시 HTML 문자는 이스케이프한다. 기존 canonical page content의
  Markdown 생성 함수는 변경하지 않는다.
- 현재 페이지/블록 연결을 확인하며 다른 페이지를 추가로 읽지 않는다.
  이미 브라우저에 읽은 데이터의 회수/DRM 기능을 제공한다는 의미는 아니다.
- 이번 기능은 텍스트 내보내기이며 원본 전체 음성 녹음 보관 기능은 추가하지 않는다.
- AGENTS.md, SBE 계약, 공통 모델/bridge, 서버 API, notion.js는 변경하지 않는다.
