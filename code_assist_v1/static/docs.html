접속 기준: 10521 현재 서비스 · 10322 Notion Workspace

화면은 현재 UI에 예시 자료를 넣은 설명용 캡처입니다. 계정·권한·모델 연결에 따라 표시 항목이 달라집니다.

처음 사용하는 업무 흐름

  1. 지식공간을 선택합니다. 개인 Wiki부터 시작하면 편합니다.
  2. 자료 업로드로 장기 지식을 등록하거나 Workspace에 이번 작업 자료를 첨부합니다.
  3. 질문 후 인용한 Wiki와 원문 조건을 확인합니다.

장기 재사용 자료는 Wiki, 현재 작업 자료는 Workspace에 둡니다. 범위를 바꿀 때는 새 대화로 이어갑니다.

메인 화면의 조작 위치

지식공간과 읽기·작성 권한

선택 범위읽기 대상작성 권한
개인 Wiki내가 소유한 해당 Wiki해당 Wiki 소유자
Part소속 Part의 공동 지식활성 Part 구성원
팀팀 고유 문서 + 하위 Part 집계팀 고유 문서: 현재 팀장
담당담당 고유 문서 + 하위 조직 집계담당 고유 문서: 현재 담당 책임자

상속 문서는 원래 조직의 권한으로 관리합니다. 관리자 계정이라는 이유만으로 일반 문서 작성 권한을 얻지는 않습니다.

개인 Wiki 목록과 관리

  1. 왼쪽 내 지식에서 Wiki를 선택합니다. 기본 Wiki와 프로젝트별 Wiki를 구분할 수 있습니다.
  2. Wiki 메뉴에서 이름 변경·기본값 지정·보관/복원을 사용합니다. 표시되는 메뉴는 권한에 따라 달라집니다.
  3. 상단 선택 목록은 내 활성 Wiki와 접근 가능한 조직 범위를 표시합니다.

자료 업로드와 대화 지식화

  1. 입력창의 ＋에서 자료 업로드를 선택하고 발행 대상을 확인합니다.
  2. 파일 추출·Wiki 작성이 끝나면 미리보기에서 본문과 발행 대상을 확인하고 게시합니다. 여러 파일은 파일별 진행 상태를 확인합니다.
  3. 대화 지식화는 저장할 대화 범위와 미리보기를 확인한 뒤 게시합니다.

이 실행 배포는 업로드 미리보기 확인 후 게시하는 흐름입니다. 최신 개발본의 자동 발행 흐름과 차이가 있습니다. 대화 지식화도 미리보기를 확인한 뒤 게시합니다.

Wiki 본문과 개정 이력

  1. 지식 탭에서 문서 제목을 눌러 본문을 엽니다.
  2. 원문에서 유지해야 할 수치·단위·예외 조건을 확인합니다.
  3. 문서 아래 개정 이력으로 변경 시점과 사유를 확인합니다.

Markdown과 원본 파일

버튼사용 목적확인 사항

Wiki 열람과 보호 원본 다운로드 권한은 별도로 판단할 수 있습니다. 실패 안내가 나오면 문서 소유자 또는 담당자에게 문의합니다.

질문 작성과 근거 확인

  1. 업무 대상과 필요한 출력 형식을 함께 적습니다. 예: “선택 Wiki에서 점검 절차를 찾고 예외 조건까지 표로 정리해줘.”
  2. 답변에 표시한 문서·인용 내용을 열어 결론이 원문과 맞는지 확인합니다.
  3. 조건·부정 표현·수치는 업무에 적용하기 전에 원문과 대조합니다.

화면의 답변은 기능 설명용 예시입니다. 실제 모델 품질 보장이나 회사 API 실행 결과가 아닙니다.

조직 Wiki와 상속 문서

  1. 상단에서 팀 또는 담당을 선택하면 권한 있는 하위 지식을 함께 조회합니다.
  2. 상속 문서는 읽기 전용으로 표시됩니다. 수정은 원래 Part 또는 소유 조직에서 진행합니다.
  3. Index·Log·Graph도 선택한 범위에 맞춰 확인합니다.

관계 그래프와 고정 자료

  1. 지식 화면의 그래프에서 관련 문서와 관계 근거를 확인합니다.
  2. 필요한 문서를 대화에 고정할 수 있습니다. 고정 자료도 현재 권한을 충족해야 합니다.
  3. 그래프 연결만으로 문서 결론이 맞다고 판단하지 않고 실제 본문을 함께 읽습니다.

Workspace·스킬·기억

  1. Workspace에는 이번 작업에서 참고할 파일을 첨부하고 포함 여부를 선택합니다.
  2. 스킬 탭이나 입력창 /에서 반복 업무의 절차·출력 형식을 선택합니다.
  3. 기억은 답변 선호와 작업 규칙에 사용합니다. 업무 근거가 필요한 자료는 Wiki로 등록합니다.
