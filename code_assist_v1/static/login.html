사번과 비밀번호로 로그인하세요.

로그인 안내

계정 ID: 본인 사번

초기 비밀번호: user1234

처음 접속할 때

  1. 사번을 입력합니다.
  2. 초기 비밀번호 user1234를 입력합니다.
  3. 로그인 후 표시되는 비밀번호 변경 창에서 개인 비밀번호로 바꿉니다.
  4. 변경이 완료되면 다시 접속되어 작업을 시작할 수 있습니다.

계정이 없을 때

일반 사용자는 직접 계정을 만들 수 없습니다. 신규 계정이 필요하면 관리자에게 사번과 이름을 전달해 계정 생성을 요청하세요.

로그인이 되지 않을 때

  • 사번을 정확히 입력했는지 확인하세요.
  • 비밀번호가 변경된 적이 있으면 변경된 비밀번호를 사용하세요.
  • 초기 비밀번호로 접속한 뒤에는 반드시 개인 비밀번호로 변경해야 합니다.
  • 계정이 아직 생성되지 않았다면 관리자에게 요청하세요.
